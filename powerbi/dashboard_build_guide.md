# Power BI dashboard build guide

## Import
1. Run `python src/analyze_sales.py`.
2. In Power BI Desktop, Get Data → Text/CSV and import `data/processed/clean_sales.csv`.
3. Set InvoiceDate to Date/Time, Revenue and UnitPrice to decimal number, Quantity to whole number, CustomerID to text (IDs are identifiers), and Country/Description to text.
4. Create measures from `DAX_measures.txt`.

## Recommended one-page layout
- Header: “Sales Performance & Business Insights” and date range.
- KPI cards: Total Revenue (£), Total Orders, Units Sold, Known Customers, Average Order Value (£).
- Line chart: Revenue by YearMonth. Sort YearMonth ascending.
- Bar chart: Top 10 products by revenue.
- Bar/map (optional): Revenue by country; a bar chart is more reliable if map visuals are unavailable.
- Column chart: Orders or revenue by weekday.
- Slicers: YearMonth, Country, Description.

## Validation
- Confirm KPI totals match `reports/summary.json` and `monthly_kpis.csv`.
- Check that cancellations and negative quantities are excluded from positive-sales KPIs.
- Add a note: “Revenue calculated as Quantity × UnitPrice; currency GBP. Dataset covers historical transactions and does not imply current business performance.”
- Save the report as `powerbi/Sales_Performance_Dashboard.pbix` locally. PBIX is created in Power BI Desktop; it cannot be generated by this Python project.
