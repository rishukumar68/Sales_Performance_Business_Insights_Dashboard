# Sales Performance & Business Insights Dashboard

A portfolio project demonstrating descriptive analytics with **Excel, SQL, Python, Pandas, NumPy, and Power BI**. No machine learning is used. The project studies sales trends, product performance, country-level performance, order value, and customer purchasing patterns.

> **Dataset note:** The included `sample_sales_synthetic.csv` is synthetic test data used only to verify that the pipeline runs. For the final portfolio analysis, use the real UCI Online Retail dataset and clearly report metrics from that run. Do not present synthetic sample metrics as real business findings.

## Dataset
Use the [UCI Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online%2Bretail), provided under CC BY 4.0. It contains 541,909 transaction rows from a UK-based online retailer, covering 1 December 2010 through 9 December 2011. Cite the dataset as: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33.

Download `Online Retail.xlsx` from UCI and place it in `data/raw/Online Retail.xlsx`. The Python script prefers this file when present.

## Run locally (Windows / VS Code)
1. Install Python 3.10+ and create a virtual environment.
   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Place UCI's `Online Retail.xlsx` into `data/raw/`. If absent, the included synthetic sample is used for a smoke test.
3. Run `python src/analyze_sales.py`.
4. Outputs are saved in `data/processed/` and `reports/summary.json`.
5. Import `clean_sales.csv` into Power BI Desktop and follow `powerbi/dashboard_build_guide.md`.
6. Open the generated Excel summary workbook after running `python src/build_excel_report.py`.

## Analysis questions
- How does revenue change month to month?
- Which products contribute the most revenue and units sold?
- Which countries contribute the most sales?
- What are the order count and average order value?
- Which days of the week show the highest sales?
- How concentrated is revenue among top products?

## Data quality and metric definitions
- Exact duplicate rows are removed. Rows missing core sales fields are excluded.
- Invoice numbers beginning with `C`, non-positive quantities, and non-positive prices are excluded from positive-sales KPIs. This is a documented analytical choice; cancellation rows remain excluded from revenue analysis rather than modeled as returns.
- Revenue = Quantity × UnitPrice. Currency is GBP (£).
- Customer counts include only known/non-null CustomerID values.
- Dataset is historical; findings describe the dataset period, not present-day market conditions.

## Excel
Run `python src/build_excel_report.py` after the analysis to create `excel/Sales_Performance_Summary.xlsx` with KPI summary and product/monthly/country breakdowns. Use Excel PivotTables or import the cleaned output to create additional interactive pivots as a follow-up.

## Limitations
This is a portfolio analysis, not a production reporting system. The dataset contains cancellations, missing customer IDs, and potentially unusual transactions. The cleaning rules are transparent but can affect totals. No causal claims, forecasting, or machine-learning predictions are made.
